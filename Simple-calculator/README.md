# Simple Calculator

[View the Live Demo](https://praiz-y.github.io/javascript-fundamentals-projects/Simple-calculator)

A basic calculator built with **HTML, CSS, and Vanilla JavaScript** that supports standard arithmetic, keyboard input, and a light/dark theme toggle.

## Features

- Add, subtract, multiply, and divide
- Keyboard support (numbers, operators, Enter, Backspace)
- Calculation history (last 5 results)
- Sign toggle (±) and backspace
- Paste support for expressions
- Light/dark theme switch
- Error handling for invalid expressions

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

## Getting Started

1. Open the project folder
2. Open `index.html` in your browser
