# Sticky Notes Task App

 [View the Live Demo](https://praiz-y.github.io/javascript-fundamentals-projects/Sticky-ToDo-List/)

## Description

This is a simple sticky notes style task management application built with HTML, CSS, and JavaScript. The app allows users to create, view, and organize tasks in a visual sticky-note layout.

## Features

* Add new tasks
* Display tasks as sticky notes
* Responsive layout
* Subtle background grid texture
* Clean and minimal user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```
project-folder
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

The app displays tasks as cards styled like sticky notes. A background grid texture is applied to create a paper-like interface. JavaScript handles the creation and management of tasks.

## Getting Started

1. Clone the repository
2. Open the project folder
3. Open `index.html` in your browser
